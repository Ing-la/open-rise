# 注意事项

## 生产环境数据库初始化（当前设计）

当前 `package.json` 的 `prebuild` 脚本：

```json
"prebuild": "prisma migrate diff --from-empty --to-schema-datamodel prisma/schema.prisma --script > prisma/schema.sql"
```

### 设计意图

**每次发版都当作用户第一次下载软件。**  `--from-empty` 输出的是当前 schema 的完整 `CREATE TABLE` DDL，不含任何迁移逻辑。运行时在一张空白纸上建表，简单直接。

这是 V1 阶段最轻量的做法，没有历史包袱。

### 什么情况下需要改

当项目**已经有真实用户数据**，且后续版本需要在**已有表上新增列**时，当前方案失效。因为 `--from-empty` 只输出 `CREATE TABLE`，不包含 `ALTER TABLE ADD COLUMN`。

届时需要改用临时空数据库 + `db push --dry-run --print` 方案：

```bash
# 构建时：创建临时空库，生成同时包含 CREATE TABLE 和 ALTER TABLE 的 DDL
DATABASE_URL="file:./prisma/tmp.db" npx prisma db push --dry-run --print > prisma/schema.sql
rm -f prisma/tmp.db
```
