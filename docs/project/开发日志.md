## 2026-05-19 14:28 [06-agent-f]

### Agent 记忆压缩重构：持久化压缩 + DB 清理 + 前端思考过程展示

**背景：** 旧方案只有内存压缩（microCompact/autoCompact），DB 只增不删，跨重启后重复压缩全量历史，不合理。

**新方案 — compactSession：**
- Agent 运行积累 > 40,000 token 时触发 `compactSession()`
  1. 当前 session 的全部 `AgentMessage` 以 **append 模式** 追加到 `prisma/agent-archives/{roleName}-{sessionId}.jsonl`（一个 session 一个文件）
  2. 调用 LLM 生成压缩摘要（含 task goal、accomplished、remaining）
  3. 成功后从 DB 删除已归档消息，写入 `AgentSession.summary` + `compactedAt`
